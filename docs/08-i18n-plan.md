# i18n implementation plan

Status: Phases 0-9 implemented (Paraglide JS foundation through zh-Hant translation coverage of
every key in `messages/en.json`); Phase 10 (test/QA hardening, locale-switch e2e coverage) is
still pending. The zh-Hant translation is machine-generated, not yet reviewed by a fluent Hong
Kong mahjong player — see the Risks table below.

## Decision: Paraglide JS

| Candidate | Verdict | Why |
|---|---|---|
| **Paraglide JS** | Chosen | Officially recommended for SvelteKit; Svelte 5 runes-native; SSR-safe; fully typed; compiler-emitted tree-shaken messages; good tooling. |
| `sveltekit-i18n` | Runner-up | Runes-native and SvelteKit-focused, but smaller community and faster-moving API. |
| `svelte-i18n` | Not chosen | Store-based, not runes-native; maintenance has slowed; SSR locale-bleed risk. |
| `typesafe-i18n` | Not chosen | Excellent type safety, but not purpose-built for SvelteKit SSR/routing; more boilerplate. |

## Locale strategy

- `baseLocale = 'en'`.
- Supported locales: `['en', 'zh-Hant']`.
- Detection strategy: `['cookie', 'baseLocale']` — **no URL prefix**.
- Rationale: table invite links (`/table/ABC123`) are shared between players and must stay locale-agnostic.
- Switching: `setLocale('zh-Hant')` writes the cookie and reloads the page.

## Key conventions

- Use **semantic, namespaced keys** (e.g. `lobby_createTableButton`, `createTableDialog_title`).
- Generated functions are camelCased: `m.lobby_createTableButton()`.
- Interpolation: `"table_status_spectating": "Table {tableId} · spectating"`.
- Pluralization uses ICU: `"concealedTiles_count": "{count, plural, one {# concealed tile} other {# concealed tiles}}"`.
- Cantonese glyphs (碰/上/槓/食糊/莊) stay as untranslated labels in both locales, per `03-frontend.md` §8 and `99-deferred.md`.

## Risks and mitigations

| Risk | Mitigation |
|---|---|
| URL-prefix strategy breaks invite links | Use `['cookie', 'baseLocale']` only. |
| SSR locale bleed between requests | Use Paraglide's `paraglideMiddleware` in `hooks.server.ts`; no module-scope locale state. |
| Generated files conflict with lint/format | Add `src/lib/paraglide` to ignore lists; regenerate via build step. |
| Tests assert on English text | Switch to `data-testid` or key-based assertions during migration. |
| zh-Hant terminology wrong | Domain-expert review; keep Cantonese call glyphs as labels. |
